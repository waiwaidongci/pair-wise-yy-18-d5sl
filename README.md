# CoreColumn 地质钻芯编录与柱状图编辑器

基于 SvelteKit、TypeScript、Vite、Skeleton 和 Svelte 5 runes 构建。柱状图、深度标尺和
多孔对比均使用 SVG，钻芯照片由浏览器 Canvas 生成，不需要外部图片或后端服务。

## 功能

- 按深度区间录入岩性、颜色、结构、蚀变、矿化和描述
- 拖动区间边界并校验连续、无重叠、无空段
- 共享深度坐标的标尺、缩放和平移
- Canvas 生成的钻芯照片缩略图与区间联动
- 多钻孔并排对比和手动地层连线
- 修改一个钻孔后对比图实时同步
- 撤销重做、结构化 JSON 导出和打印柱状图

### 对比线锚点（跟随地层层位）

每条连线记录两端锚点深度（层位中点）而不是死挂区间 id：

- **拆分区间**：按与原子段重叠最多的子段重新挂接，对端记录的目标层位同步更新
- **合并区间**：两段连向同一目标孔不同地层时标成「待重连」（琥珀虚线），由编录员人工指定新层位；目标一致则自动归并为一条
- **深度边界改动**：锚点落出本端区间或两端深度带不再重叠时，连线显式「失效」（红色虚线），原因给出两边深度，不再跳到别的地层
- **删除钻孔**：所有孔中指向它的连线成对清理，不再留悬挂线

待重连/失效连线可在对比页「问题连线」面板逐条重连或移除。

### 多标签页草稿合并

草稿以信封（`holes` + 合并基准 `baseHoles` + `revision`）存入 localStorage。两个标签页并发保存时做三向合并：按钻孔与区间标识逐段合并，不再整份覆盖；两边同改一段深度时拦截冲突并给出本页/他页深度，逐段选择保留侧后才落盘。

本地 v1 旧数据（无锚点）首次加载时按现有连线两端区间中点补出锚点；升级失败时原稿保留并备份、页面给出「重试升级」入口，绝不写入覆盖原稿。

## 运行

```bash
export PATH="/Applications/ChatGPT.app/Contents/Resources/cua_node/bin:$PATH"
corepack pnpm install
corepack pnpm build
corepack pnpm dev
corepack pnpm test   # vitest：锚点重挂、三向合并、v1 升级规则
```
